LlamaDock MCP endpoints
=======================

Light stack - started automatically by LlamaDock when MCP helpers are enabled:

Web Search / Fetch
  http://127.0.0.1:3100/mcp
  tools: search_web, search_and_fetch, fetch_url, deep_research

Filesystem
  http://127.0.0.1:3101/mcp
  allowed directory: <LLAMADOCK_ROOT>\mcp-share

Memory
  http://127.0.0.1:3102/mcp
  storage file: <LLAMADOCK_ROOT>\mcp-data\memory.jsonl


Optional stack - start with mcp-all-optional.bat when needed:

Context7
  http://127.0.0.1:3103/mcp
  usage hint: add "use context7" for coding/library documentation questions.

MarkItDown
  http://127.0.0.1:3104/mcp
  converts files and URLs to Markdown.

Playwright
  http://localhost:3105/mcp
  browser automation; heavier than the others.


BAT files
=========

Main launcher:
  <LLAMADOCK_ROOT>\llamadock.bat

Compatibility launcher:
  <LLAMADOCK_ROOT>\llama-tq3-chat.bat

Starts the light MCP stack only:
  <LLAMADOCK_ROOT>\mcp-all-light.bat

Starts Context7, MarkItDown, and Playwright:
  <LLAMADOCK_ROOT>\mcp-all-optional.bat
